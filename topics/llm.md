# 大语言模型的原理：从"预测下一个词"到 Transformer

> 状态：第一阶段（语言模型）、第二阶段核心（自注意力）已写 · 更新：2026-11-22
> 标注：**[已证]** 给出了推导 · **[事实]** 标准结论 · **[直觉]** 帮助理解、不严格

---

## 1. 问题

大模型（GPT、Claude、Llama 等）在数学上到底是什么？它是怎么训练出来的，内部又是怎么"读"一段文字的？

一句话的答案：**它是一个条件概率分布 $p_\theta(\text{下一个 token}\mid\text{前文})$，参数 $\theta$ 用最大似然在海量文本上拟合；而计算这个分布的函数，是一个叫 Transformer 的神经网络。**

本文按顺序拆开这句话。

---

## 2. 背景与动机

- 只会用、不懂原理时，很多现象只能死记：上下文窗口为什么有上限，长文本为什么贵，模型为什么会一本正经地编造（"幻觉"）。懂了原理，这些都能从结构上推出来。
- 和我熟悉的东西有直接联系：
  - 语言模型本质是一个随机过程，n-gram 模型就是有限阶的马尔可夫链；
  - 训练就是最大似然估计；
  - 生成文本就是从这个链里采样。

  大模型的新东西在于：条件分布不再是一张查表，而是一个能"看整段上下文"的参数化函数。

---

## 3. 前置知识

- **概率**：条件概率、链式法则 $p(x_1,\dots,x_T)=\prod_t p(x_t\mid x_{<t})$、最大似然估计。
- **线性代数**：矩阵乘法、内积、softmax。
- **优化**：梯度下降。神经网络可以看成一个很大的可微函数，用反向传播算梯度。本文不展开这一部分，代码里只做前向计算。

## 4. 推导

### 4.1 语言模型 = 下一个 token 的条件分布 **[事实]**

**token**：文本先被切成一个个 token（大致是词或词的片段），每个 token 对应词表里的一个编号。词表大小记为 $V$，现实中的模型一般是几万到十几万。

由链式法则，一段文本的概率可以拆开：
$$p(x_1,\dots,x_T)=\prod_{t=1}^T p(x_t\mid x_1,\dots,x_{t-1}).$$
所以只要会算"给定前文，下一个 token 的分布"，就等于会算整段文本的概率。**语言模型就是这个条件分布。**

**生成文本**：从这个分布里抽一个 token，接到末尾，再抽下一个，如此重复。这叫自回归（autoregressive）生成。

### 4.2 训练目标：最大似然 = 最小化交叉熵 **[已证]**

给定训练文本 $x_1,\dots,x_N$，最大化对数似然
$$\sum_t\log p_\theta(x_t\mid x_{<t}).$$
等价地，最小化平均负对数似然：
$$\mathcal L(\theta)=-\frac1N\sum_t\log p_\theta(x_t\mid x_{<t}).$$
这就是"交叉熵损失"。它的含义是：模型给**真实出现的下一个 token** 分配的概率，取对数后求平均，再加负号。

**困惑度**（perplexity）定义为 $\mathrm{PPL}=e^{\mathcal L}$。直观上，它相当于"模型平均在多少个候选里犹豫"：
- 完全瞎猜（均匀分布）时 $\mathrm{PPL}=V$；
- 完美预测时 $\mathrm{PPL}=1$。

### 4.3 最简单的例子：bigram 模型 **[已证]**

假设下一个字符只依赖前一个字符：$p(x_t\mid x_{<t})=p(x_t\mid x_{t-1})$。这就是一阶马尔可夫链，参数是一个 $V\times V$ 的转移矩阵 $P$。

**最大似然解就是数频率**：
$$\hat P(b\mid a)=\frac{\#\{a\text{ 后面紧跟 }b\}}{\#\{a\}}.$$
证明：对每一行分别最大化 $\sum_b n_{ab}\log P(b\mid a)$，约束是 $\sum_bP(b\mid a)=1$。用拉格朗日乘子即得 $P(b\mid a)\propto n_{ab}$。$\blacksquare$

**它的两个根本局限**：
1. **只看一个字符**。想看前 $k$ 个，参数量变成 $V^{k+1}$，指数爆炸。
2. **没见过的组合概率为 0**。测试集里一出现就是 $\log0=-\infty$，只能靠平滑（给所有计数加一个 $\alpha$）硬补。

神经语言模型同时解决这两点：
- 用一个参数量固定的函数代替查表，所以能看很长的上下文；
- 把 token 映射成向量（embedding），相似的 token 有相似的向量，于是没见过的组合也能"类比"出合理的概率。

### 4.4 从 token 到向量：embedding **[事实]**

每个 token 编号 $i$ 对应一个可学习的向量 $e_i\in\mathbb R^{d}$（$d$ 通常是几百到几千）。一段长度为 $T$ 的文本于是变成矩阵 $X\in\mathbb R^{T\times d}$，第 $t$ 行是第 $t$ 个 token 的向量。

**位置信息**：注意力本身不区分顺序（见 4.5），所以还要把"第几个位置"的信息加进去，即位置编码，一般直接加到 $X$ 上。

模型最后一层会把每个位置的向量映射成 $V$ 维的打分（logits），再用 softmax 变成下一个 token 的概率：
$$\mathrm{softmax}(z)_j=\frac{e^{z_j}}{\sum_ke^{z_k}}.$$

### 4.5 自注意力：每个位置按相关性读取其他位置 **[事实 + 直觉]**

**要解决的问题**：位置 $t$ 预测下一个 token 时，需要从前文里取出有用的信息。但有用的信息可能在任何地方，比如十句话之前提到的人名。

**做法**：每个位置的向量 $x_t$ 经三个矩阵变换出三个向量：
- **query** $q_t=x_tW_Q$："我在找什么"；
- **key** $k_s=x_sW_K$："我这里有什么"；
- **value** $v_s=x_sW_V$："如果你选中我，我给你的内容"。

位置 $t$ 对位置 $s$ 的打分是内积 $q_t\cdot k_s$，经 softmax 变成权重。输出是 value 按这些权重的加权平均。写成矩阵形式：
$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\Big(\frac{QK^\top}{\sqrt{d}}+M\Big)V.$$

**三个关键细节**：
1. **因果掩码 $M$**：语言模型预测第 $t+1$ 个 token 时不能偷看后面，所以 $M$ 在 $s>t$ 处取 $-\infty$，softmax 之后这些位置的权重恰好为 0。注意力矩阵因此是**下三角**的。
2. **为什么除以 $\sqrt d$**：
   - 设 $q,k$ 的各分量独立、均值 0、方差 1，则 $q\cdot k=\sum_{i=1}^dq_ik_i$ 的方差是 $d$。
   - $d$ 很大时，打分的量级很大，softmax 会退化成接近 one-hot 的分布。这时梯度几乎为 0，学不动。
   - 除以 $\sqrt d$ 把方差拉回 1。
3. **为什么说它不区分顺序**：如果把输入的行打乱，输出也只是相应地打乱。所以顺序信息必须靠位置编码额外提供。

**多头注意力**：把上面的计算在 $h$ 组较小的 $W_Q,W_K,W_V$ 上并行做 $h$ 次，输出拼起来。不同的头可以学到不同类型的关系，比如一个头看语法、一个头看指代。

### 4.6 一个 Transformer 块 **[事实]**

一个块（block）由两个子层组成，每个子层都带残差连接和归一化（LayerNorm）：
$$X\leftarrow X+\mathrm{MultiHeadAttention}(\mathrm{LN}(X)),\qquad X\leftarrow X+\mathrm{FFN}(\mathrm{LN}(X)).$$
- **注意力子层**：在位置之间交换信息。
- **前馈子层（FFN）**：对每个位置单独做一个两层的全连接网络，可以理解成"对取到的信息做加工"。
- **残差连接**：让信息和梯度能直接穿过很多层，深层网络才训练得动。

GPT 类模型就是把这样的块堆几十到上百层，最后接一个输出层得到下一个 token 的概率。

### 4.7 由结构直接推出的几个现象 **[直觉]**

- **上下文窗口有上限、长文本贵**：注意力要算 $T\times T$ 的打分矩阵，计算量随长度平方增长。
- **生成时可以缓存**：生成第 $t+1$ 个 token 时，前面位置的 $K,V$ 不变，可以存起来复用，这就是 KV cache。
- **"幻觉"**：模型的目标只是给出"像训练文本"的下一个 token 分布，并没有"核对事实"这一步。流畅和正确是两件事。

## 5. 数值实验

代码：[`code/llm_basics.py`](../code/llm_basics.py)，只依赖 numpy，`python3 llm_basics.py` 直接运行。

### 5.1 bigram 模型：最大似然、困惑度、过拟合

在一小段《哈姆雷特》独白上训练字符级 bigram 模型（词表 $V=19$），后一小段做测试：

| 平滑 $\alpha$ | 训练集困惑度 | 测试集困惑度 |
|---|---|---|
| 0.01 | 3.88 | **134.51** |
| 0.1 | 4.65 | 34.27 |
| 1.0 | 8.74 | 18.67 |

- 平滑越弱，训练集越好，测试集越差。
- $\alpha=0.01$ 时测试集困惑度 134，**比瞎猜（19）还差得多**：测试集里出现了训练集没见过的字符对，模型给了它们几乎为 0 的概率，于是 $-\log p$ 非常大。这就是 4.3 说的局限 2，也是最朴素的过拟合。
- 采样结果是 `tin atrherrr t tgsind bliofwwslin ...`：局部像英文（字母组合合理），整体没有意义。因为模型只看前一个字符。

### 5.2 因果自注意力

取 $T=6$ 个位置，$d_{\text{model}}=16$，$d_{\text{head}}=8$，随机权重：

```
注意力矩阵（第 i 行 = 位置 i 分给各位置的权重）：
[[1.   0.   0.   0.   0.   0.  ]
 [0.72 0.28 0.   0.   0.   0.  ]
 [0.37 0.16 0.48 0.   0.   0.  ]
 [0.05 0.12 0.34 0.48 0.   0.  ]
 [0.05 0.1  0.28 0.38 0.19 0.  ]
 [0.44 0.13 0.09 0.07 0.08 0.19]]
```

- 下三角，右上角全为 0，每行之和为 1：每个位置只在"自己和之前"的位置上分配注意力。
- **因果性验证**：只改动最后一个 token 的输入，前 5 个位置的输出变化是 $0.00$（精确为 0），最后一个位置变化 8.47。

### 5.3 为什么除以 $\sqrt d$

| $d$ | 打分方差（不缩放） | 打分方差（除以 $\sqrt d$） |
|---|---|---|
| 4 | 4.1 | 1.02 |
| 64 | 63.6 | 0.99 |
| 1024 | 1042.6 | 1.02 |

$d=1024$ 时，不缩放的 softmax 最大权重是 0.999，几乎是 one-hot；缩放后是 0.284，分布正常。和 4.5 的推导一致。

## 6. 结论与疑问

**搞懂了什么**：
- 大模型 = 下一个 token 的条件分布，训练 = 最大似然，生成 = 逐个采样。
- bigram 模型是最简单的实例，它的两个局限（看不远、没见过就是 0）正好说明了为什么需要神经网络和 embedding。
- 自注意力 = 每个位置用 query 去匹配所有之前位置的 key，再按权重读取 value。因果掩码保证不看未来，$\sqrt d$ 保证 softmax 不退化。

**还没写的（后续阶段）**：
1. **第三阶段，动手训练**：用反向传播真正训练一个小 GPT，看损失曲线下降、生成文本变好。准备跟 Karpathy 的 nanoGPT 走一遍。
2. **第四阶段，"大"是怎么来的**：
   - scaling law（损失随参数量、数据量、算力按幂律下降）；
   - 从"会续写"到"会对话"：指令微调与 RLHF；
   - 推理：KV cache、采样温度、长上下文。

**疑问**：
- 注意力权重是不是真能解释成"模型在看哪里"？可解释性研究里对此有争议，值得专门看。
- 位置编码有好几种（正弦、可学习、旋转位置编码 RoPE），它们对长上下文外推的影响是什么？
