# Math learning · 项目说明

这里用来学习和研究我感兴趣的数学问题。每个问题或主题一篇笔记，随时追加。

## 目录约定

- `README.md`：本文件，项目说明和索引
- `topics/<主题>.md`：系统学习某个领域的笔记（例：`topics/number-theory.md`）
- `problems/<问题名>.md`：单个问题的研究记录（例：`problems/collatz.md`）
- `code/`：用来验证或探索的代码笔记（Python 为主）
- `llm/`：《大模型原理》笔记，按书的结构组织（第 1–6、8–18 章 + 附录 A、C），配套代码在 `llm/code/`
- `site/`：《大模型原理》的网页版。`python3 site/build.py` 把 `llm/` 生成成 `site/index.html`（单文件，浏览器直接打开；公式在构建时用 KaTeX 渲染）

## 笔记结构（每篇按顺序写，自成一体）

1. **问题 / 主题**：一句话说清楚要研究什么
2. **背景与动机**：为什么感兴趣，和已知内容的联系
3. **前置知识**：需要的定义、定理，简短列出
4. **推导与证明**：一步一步写，关键步骤标注理由
5. **数值实验**：用代码验证或找规律，代码带注释
6. **结论与疑问**：搞懂了什么，还剩什么没懂
7. **参考资料**：书、论文、链接

## 书写约定

- 公式用 LaTeX：行内 `$a^2+b^2=c^2$`，独立公式用 `$$ ... $$`
- 代码示例必须带注释，能直接运行
- 猜想和已证明的结论要分开标注：**[猜想]** / **[已证]**
